# hidraw

Linux hidraw for daemons: sysfs discovery, feature and input reports, poll with timeout, device-gone detection.

Extracted from [razerd](https://github.com/GregDuhamel/razerd), [thermaltaked](https://github.com/GregDuhamel/thermaltaked) and [HeadsetBatteryIndicator](https://github.com/GregDuhamel/HeadsetBatteryIndicator). Work in progress.
